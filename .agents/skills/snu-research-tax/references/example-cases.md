# 법인회계 우선 가상 사례 (실제 회계·세법 판단 결과가 아님)

| 가상 사실관계 | 기대 행동 |
|---|---|
| 국립대학법인 서울대학교가 유료 교육프로그램 운영 | 등록금/교육용역의 VAT 면세 여부, 수익사업성, 계약과 회계 인식 각각 확인 |
| 법인회계 주차장 수입 | 공급·대가·사업 형태 확인 후 VAT 과세 및 법인세 수익사업 여부 별개 판정 |
| 공통관리비 매입세액 100만 원 | 관련 과세·면세 공급 비율과 법령 요건을 확인한 후 공통매입세액 안분 도구 사용 |
| 서울대 법인회계 FY2027: 2027-03-01~2028-02-29 | 종료일만으로는 2028-12-31 일몰 안에 해당하지만 실제 법인세 사업연도·특례 적용 요건 별도 확인 |
| 서울대 법인회계 FY2028: 2028-03-01~2029-02-28 | 종료일이 공표된 일몰 뒤이므로 upstream 계산기 year=2028 입력만으로 100% 준비금 허용 금지 |
| 발전기금 명의 기부금 | 법적 납세주체 및 서울대 법인과 회계 경계 먼저 확인 |
| 법인회계 해외 소프트웨어 구독 | 대리납부 VAT, 공급장소, 비거주자 원천세 각각 별도 판정 |
| 연구비 전문가활용비 200,000원 | 보조 업무. 거주자성·소득유형·필요경비·과세최저한 확인 후 원천세 계산 |

실제 결산 수치, 납세번호, 개인 인사자료는 외부 계산 도구에 전달하지 않는다.
