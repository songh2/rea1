# 공식 근거·보안 검증

## 법인회계 우선 근거

- 국립대학법인 서울대학교 설립·운영에 관한 법률 제19조(회계연도) 및 서울대학교 내부 회계 규정. 시행일과 실제 결산·사업연도 확인: https://www.law.go.kr
- 법인세법 제4조(비영리법인 수익사업)·제29조(고유목적사업준비금)·제113조(구분경리), 조세특례제한법 제74조의 대학법인 특례와 종료일을 지급/신고 기준 최신 시행본으로 확인.
- 부가가치세법·시행령: 교육용역, 임대, 연구·수탁계약, 매입세액, 역외 서비스 대리납부의 개별 거래 요건 확인.
- 국세청: https://www.nts.go.kr (비영리법인 안내, 법인세·부가세·원천징수). 원문 조문과 공식 문서 URL·시행일을 답에 기재.
- 서울대학교 실제 회계규정, 법인회계 지침, 산학협력단 규정은 확인되지 않은 내용을 지어내지 말고 내부 담당자 확인 필요로 남긴다.

## 보안·실행

주민번호·외국인등록번호·여권번호·실명·계좌번호·실제 사업자번호·계약서·비공개 법인회계 장부를 외부 MCP 또는 공개 GitHub에 넣지 않는다. Upstage PDF 도구는 API 키 설정 시 외부 서비스로 문서가 전송될 수 있다. 계산·원장 요약은 로컬 익명 데이터만 사용한다. 신고·결재·납부·전표 생성/수정은 승인 없이 실행하지 않는다.
